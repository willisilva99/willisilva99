#### 🤖 **`Bot-nova-era`**
* *Descrição:* 📡 Protocolo de Comunicação de Emergência: Um bot para Discord projetado para coordenar esquadrões de sobreviventes, gerenciar recursos escassos e emitir alertas sobre hordas iminentes.

#### 📜 **`leitura.bot`**
* *Descrição:* 🗝️ Decodificador de Dados Antigos: Bot especializado em extrair e exibir informações crípticas de terminais HTML recuperados, desvendando segredos do velho mundo.
* *Tecnologias:* `Python`, `HTML (parsing)`

#### 🕹️ **`jogo-bot`**
* *Descrição:* ⚔️ Simulador de Sobrevivência Tática: Módulo de treinamento interativo operado via bot, forjando meu esquadrão para os perigos implacáveis que espreitam lá fora.
* *Tecnologias:* `Python`

#### 💰 **`economia-nova-era`**
* *Descrição:* ⚖️ Sistema de Escambo e Gestão de Recursos: Ferramenta essencial para administrar a frágil economia do nosso enclave pós-apocalíptico, com módulos adaptados para cenários de "Apocalipse Zumbi".
